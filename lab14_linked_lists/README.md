## Задание на Оценку 3:

1) Создать структуру узла, состоящего из данных и указателя на следующий узел. В качестве данных взять структуру из прошлой практической либо предлагаемую (уровень/комната Roguelike игры).

2) Написать функции: по добавлению узла в конец односвязного списка и вывод списка на экран.

3) Создать односвязный список из n элементов, заполненных случайными данными. Вывести список на экран. N – вводить с клавиатуры/аргументами main.

---

## Задание на Оценку 4:

4) Добавить в структуру узла указатель на структуру. Добавить в функцию создания узла инициализацию этого указателя.

5) Реализовать двусвязный список согласно одному из вариантов ниже. Добавить указатель S на начало списка.

6) Добавить интерфейс с вводом с клавиатуры кнопок WASD или цифр 2,4,6,8 для прохода по списку. При перемещении выводим информацию о текущем узле. Если перемещение невозможно – выводим на экран сообщение.

Пример: начинаем с S, выводим на экран текущее значение, вводим 'D' (или '6') – выполняем перемещение вправо по списку на один элемент если это возможно, в противном случае сообщить, что достигли конца списка и предложить вернуться в начало списка в позицию S (начало).
