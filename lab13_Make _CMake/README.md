## 📝 Задание на оценку 3

Сначала возьмём код из предыдущей практической работы и адаптируем его:

1. **Разбить код по каталогам:**
   - `src/` – все файлы исходного кода (`.c`)
   - `include/` – все заголовочные файлы (`.h`)

2. **Написать Makefile в корне проекта** для автоматизации сборки.

3. **В Makefile реализовать сборку и линковку статической или динамической библиотеки** (на ваш выбор).

4. **Обязательно наличие целей:**
   - `all` – полная сборка проекта
   - `clean` – удаление всех скомпилированных файлов (`.o`, `.a`, `.so` и исполняемого файла)

## 📈 Задание на оценку 4

Ко всему выше сделанному (на базе решения на оценку 3) добавить:

5. **Создать `CMakeLists.txt` в корне проекта.**

6. **Описать сборку проекта через CMake** в `CMakeLists.txt`.

7. **Добавить возможность выбора типа библиотеки при конфигурации.**  
   Использовать опцию `-D` (например, `-DBUILD_SHARED=ON`).

8. **Уметь объяснить, на что влияет опция `-DCMAKE_BUILD_TYPE`** (значения `Debug`, `Release`).
