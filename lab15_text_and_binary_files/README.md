# Лабораторная работа: Текстовые и бинарные файлы

![Текстовые и бинарные файлы](https://i.pinimg.com/736x/fe/84/9e/fe849e3529e255ef72ec03de2f4acc66.jpg)

---

## Общие требования:

• Программа должна обрабатывать возможные ошибки, такие как ошибка открытия файла или ошибка записи/чтения.

---

## Задание на оценку 3:

1) Программа получает имя файла через аргументы командной строки: `./program staff.csv`.

2) Считать файл `staff.csv`. Каждая строка имеет вид: `Elon Musk;5001;Level_A`. Можно сгенерить нейронкой.

3) Использовать `fgets()` для чтения строки и `strtok()` (или `sscanf`) для разделения полей по символу `;`.

4) Вывод в консоль отформатированной таблицы со всеми сотрудниками.

---

## Задание на оценку 4:

5) Сохранить массив полученных структур в файл `database.dat`, используя `fwrite()`.

6) Написать функцию поиска, которая открывает `database.dat`, считывает его через `fread()` и запрашивает у пользователя ID.

7) Если сотрудник найден — вывести его данные на экран. Если нет — выдать ошибку.
