## Задание 

Разработать программу palindrom, выполняющую поиск всех палиндромов в заданном
тексте. Программа принимает в качестве аргумента командной строки имя файла,
содержащего текст на русском языке. Палиндромом называется слово или текст,
читающийся одинаково в обоих направлениях (например, «потоп», «а роза упала на лапу
Азора»). Все найденные палиндромы выводятся на экран
Критерии оценки :

• «Удовлетворительно»: проверка, является ли весь текст целиком палиндромом; нет
динамической памяти.

• «Хорошо»: предварительная обработка (удаление знаков препинания из каждого
предложения); проверка каждого предложения; динамическая память.

• «Отлично»: удаление всех пробелов и знаков препинания; поиск подпалиндромов
алгоритмом Манакера; динамическая память.
